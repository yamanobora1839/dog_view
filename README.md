# 犬と人間の見え方体験

スマートフォンの背面カメラ映像を、VRゴーグル向けに左右2画面で表示するWebアプリです。アプリのインストールやアカウント登録は不要です。

## 現在の機能

- ボタン操作でスマートフォンの背面カメラを起動
- 同じカメラ映像を画面の左右に表示
- 横向きでの利用を案内
- カメラ映像は端末内で表示するだけで、サーバーへ送信しない

犬の色覚変換と照準によるモード切り替えは、次の開発段階で追加予定です。

## 起動方法

カメラを使うにはHTTPSが必要です。GitHub Pagesに公開するか、ローカル開発時はlocalhost上で配信してください。`index.html`を直接開く方法では、カメラを利用できない場合があります。

1. スマートフォンでHTTPSのページを開きます。
2. 端末を横向きにします。
3. 「カメラを開始」を押し、ブラウザーからのカメラ使用許可を承認します。
4. スマートフォンを段ボール製VRゴーグルにセットします。

## プライバシー

カメラ映像は`getUserMedia`で取得し、ページ上の video 要素に直接表示します。映像をアップロードする処理や外部ライブラリはありません。カメラ使用にはブラウザーの許可が必要です。

## ファイル

- `index.html` — ページ構造とカメラ開始画面
- `style.css` — 全画面表示、左右分割、横向き案内
- `app.js` — 背面カメラ取得と左右 video 要素への表示
