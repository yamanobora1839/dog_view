# 犬と人間の見え方体験

スマートフォンの背面カメラ映像を画面いっぱいに表示し、人間の見え方と犬の色覚を近似した見え方を切り替えて体験するWebアプリです。縦向き・横向きの両方に対応します。

## 機能

- ボタン操作で背面カメラを起動・停止
- 人間モードはカメラ映像をそのまま表示
- 犬モードはCanvas上で赤・緑の差を縮め、青・黄系の差を残す色変換をリアルタイム適用
- カメラ映像は端末内で処理し、外部サーバーへ送信しない
- 外部ライブラリ不使用

犬モードは二色型色覚を参考にした近似シミュレーションです。犬ごとの見え方や実際の視覚を完全に再現するものではありません。

## 起動方法

カメラを使うにはHTTPSが必要です。GitHub Pagesに公開するか、ローカル開発時はlocalhost上で配信してください。`index.html`を直接開く方法では、カメラを利用できない場合があります。

1. スマートフォンでHTTPSのページを開きます。
2. 「カメラを開始」を押し、ブラウザーからのカメラ使用許可を承認します。
3. 「人間の見え方」「犬の見え方」ボタンで表示を切り替えます。
4. 体験を終えるときは「カメラを停止」を押します。

## プライバシー

カメラは`getUserMedia`で取得し、video要素とCanvas上で端末内処理します。映像をアップロードする処理や外部ライブラリはありません。カメラ使用にはブラウザーの許可が必要です。

## ファイル

- `index.html` — ページ構造、カメラ開始画面、見え方選択ボタンとCanvas
- `style.css` — 全画面映像表示とスマートフォン向け操作レイアウト
- `app.js` — 背面カメラ起動・停止、色変換、表示モード切り替え
