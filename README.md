# 犬と人間の見え方体験

スマートフォンの背面カメラで現実の景色を画面いっぱいに表示し、人間の見え方と犬の見え方を切り替えて体験するWebアプリです。スマートフォンの縦向き・横向きどちらでも使えます。

## 現在の機能

- ボタン操作で背面カメラを起動
- カメラ映像を画面全体にリアルタイム表示
- 「人間の見え方」「犬の見え方」を画面上の大きなボタンで選択
- カメラ停止ボタンで映像取得を終了
- 映像は端末内で表示するだけで、外部サーバーへ送信しない

現在の段階では犬の色覚変換は行わず、犬モードを選んだときに追加予定であることを表示します。

## 起動方法

カメラを使うにはHTTPSが必要です。GitHub Pagesに公開するか、ローカル開発時はlocalhost上で配信してください。`index.html`を直接開く方法では、カメラを利用できない場合があります。

1. スマートフォンでHTTPSのページを開きます。
2. 「カメラを開始」を押し、ブラウザーからのカメラ使用許可を承認します。
3. 画面上の「人間の見え方」「犬の見え方」ボタンでモードを選びます。
4. 体験を終えるときは「カメラを停止」を押します。

## プライバシー

カメラ映像は`getUserMedia`で取得し、ページ上のvideo要素に直接表示します。映像をアップロードする処理や外部ライブラリはありません。カメラ使用にはブラウザーの許可が必要です。

## ファイル

- `index.html` — ページ構造、カメラ開始画面、見え方選択ボタン
- `style.css` — 全画面映像表示とスマートフォン向け操作レイアウト
- `app.js` — 背面カメラの起動・停止とモード切り替え
